# Дизайн «Мои рецепты»

[Figma · Дизайн приложения v1](https://www.figma.com/design/KuRYRPznTlW4lr2t5XTMzk?node-id=8-252)

Созданы 16 редактируемых мобильных экранов 360 × 800:
каталог, рецепт, публикация, избранное, группы, группа, история,
попытка, новая попытка, отзывы, вход, регистрация, профиль, подписка,
участники, приглашения.

Material 3 Design Kit: поля, кнопки, нижняя навигация.
Roboto, фон #F7F9F7, основной текст #25342B, вторичный #647268,
основной цвет #356B4A, карточки #FFFFFF, мягкая заливка #E4EFE6.
Отступы экрана 24 dp; карточки 16 dp; промежутки 14 dp; радиус карточек 16 dp.
В Compose используются соответствующие компоненты Material 3.

Макет создан до реализации. Исходный сценарий создания: build-figma.js.
Прежние учебные эскизы сохранены на первой странице Figma.
Лимит Starter остановил заключительную доработку иконок и экспорт:
в макете нижняя навигация может содержать стандартные звёздочки;
в приложении установлены смысловые Material-иконки.
Комбинированные поля макета разделены в приложении для полноценного ввода.
Android-формы прокручиваются и содержат полный набор ограничений ТЗ.
