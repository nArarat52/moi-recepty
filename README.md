# Мои рецепты · 1.0.0

Android-приложение по техническому заданию проекта «Мобильное приложение рецептов».
Дата комплекта: 16 ноября 2026 года.

## Быстрый запуск

1. Запустите Docker Desktop.
2. Дважды нажмите START.cmd в этой папке. Он запустит PostgreSQL и API, затем добавит демонстрационные данные, если база ещё пуста.
3. Установите releases/MoiRecepty-1.0.0-demo.apk на Android 10+ или эмулятор.
4. В эмуляторе сервер доступен автоматически по адресу http://10.0.2.2:8000.
5. Войдите тестовым аккаунтом. Пароль всех четырёх аккаунтов: Recipe2026!

| Логин | Назначение |
|---|---|
| anna | Анна: создатель «Семейной кухни», подписка активна |
| mikhail | Михаил: участник семейной группы, создатель группы с завершённой подпиской |
| olga | Ольга: приглашённый участник без собственной подписки |
| ivan | Иван: посторонний для текущих групп, автор старой попытки; есть приглашение |

Для физического телефона с USB-отладкой выполните adb reverse tcp:8000 tcp:8000.
В приложении откройте Профиль → Подключение к серверу и задайте http://127.0.0.1:8000.
Этот способ также рекомендуется для эмулятора при нестабильной работе адреса 10.0.2.2.
START.cmd автоматически создаёт такой туннель для подключённых устройств,
если Android SDK установлен в обычной папке или указан ANDROID_HOME.
Для сетевой демонстрации используйте HTTPS; локальный APK разрешает HTTP для изолированной учебной среды.

## Реализовано

- Гостевой каталог, поиск по названию, категории и время 15/30/60 минут, загрузка порциями по 20.
- Регистрация, вход, отзыв сессии при выходе, системное защищённое хранение токена.
- Публикация и редактирование своих рецептов, ингредиенты, упорядоченные шаги, необязательное фото.
- Серверное избранное, независимые оценки 1–5 и отзывы, изменение и удаление собственного отзыва, переключение лайка/дизлайка.
- Приватные группы, приглашения, принятие и отклонение, исключение и выход участника.
- Разработки блюд и полные неизменяемые версии попыток со ссылкой на исходную.
- Демонстрационная подписка создателя; после окончания доступны история и управление участниками.
- Валидация на клиенте и сервере, подтверждение отмены формы, сохранение формы при сетевой ошибке, 15-секундный сетевой тайм-аут.
- Транзакции, защита от дубликатов после повторной отправки, проверка прав на фотографии, согласованная резервная копия.

Настоящие платежи, почта восстановления пароля, модерация, чат, генерация рецептов и офлайн-синхронизация не входят в ТЗ.

## Структура

- android/ — Kotlin, Jetpack Compose, Material 3; Gradle Wrapper.
- backend/ — Python 3.12, FastAPI, PostgreSQL 16, SQL-схема, тестовые данные и тесты.
- compose.yaml — локальный сервер и постоянный том базы.
- releases/ — установочный демонстрационный APK и контрольная сумма.
- design/ — ссылка, параметры и сценарий создания редактируемого макета.
- scripts/ — запуск, остановка, сборка, резервное копирование и восстановление.
- docs/ — инструкции, архитектура, протокол проверок.

## Сборка

В PowerShell из этой папки:

    .\scripts\Build-Android.ps1

Сборка с установкой на подключённое устройство:

    .\scripts\Build-Android.ps1 -Install

APK подписан отладочным ключом и предназначен для учебной демонстрации.
Для публикации потребуются собственный release-ключ, HTTPS-конфигурация и отдельная подготовка к магазину.
