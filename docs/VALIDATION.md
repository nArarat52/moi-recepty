# Протокол проверки · 16 ноября 2026

Проверено на Windows, Docker Desktop, PostgreSQL 16, Python 3.12 в контейнере,
JDK 21 и Android Emulator API 35. Минимальная версия приложения — Android 10 / API 29.

## API и база

15 интеграционных тестов, 0 ошибок: [JUnit XML](api-tests.xml).
Тесты работают в отдельной временной схеме PostgreSQL.

- Каталог из 200 рецептов: десять запросов, каждый быстрее трёх секунд; страницы без пересечений, совместные фильтры.
- Регистрация, регистронезависимый логин, Argon2id, сохранение пробелов пароля, отзыв токена.
- Валидация и атомарность публикации; запрет изменения чужого рецепта.
- Независимость оценки и отзыва, запрет собственного оценивания, реакции и каскадное удаление.
- Серверное избранное и защита от повторной записи.
- Приватность групп и фотографий, немедленная потеря доступа после исключения.
- Истёкшая подписка, продление, приглашения и членство.
- Полные неизменяемые снимки попыток, родитель из того же блюда, конкурентная нумерация.
- Повтор одного ключа операции возвращает прежний результат; изменённое тело с тем же ключом отклоняется.
- Искусственный сбой после INSERT откатывает транзакцию; повтор создаёт ровно одну запись.
- Формат и размер фото, защищённая загрузка.

## Android

Итоговый прогон: **7 тестов, 0 ошибок**, сборка assembleDebug успешна.
Android Lint: 0 ошибок; замечания о доступных обновлениях зависимостей
и рекомендациях Android сохранены в полном отчёте.

Автоматические сценарии: поиск и рецепт гостя; вход и избранное; история группы,
копирование попытки и отмена; валидация с сохранением ввода;
запрет записи в группе с истёкшей подпиской; создание и удаление отзыва;
чтение после простоя соединения.

При итоговой проверке найдено закрытое сервером keep-alive-соединение:
GET теперь восстанавливается средствами OkHttp в пределах 15 секунд,
изменяющие запросы используют новое соединение и не повторяются автоматически.
Это сохраняет семантику переключения реакций и продления подписки.

Окончательный прогон использует прямой ADB-туннель 127.0.0.1:8000:
NAT эмулятора по адресу 10.0.2.2 периодически завершал запросы тайм-аутом.
Для этого подключения нужен adb reverse; настройка описана в инструкции.

Отчёты: [UI-тесты](reports/android-ui-tests.xml),
[Android Lint](reports/android-lint.html).

## Комплект и ограничения

Включены исходный код, Gradle Wrapper, APK с контрольной суммой,
Docker Compose, схема API, скрипты запуска и резервного копирования.
Демонстрационный набор: четыре аккаунта, 20 рецептов, пять отзывов,
две группы, два блюда и по три попытки в каждом.

APK подписан отладочным ключом. Проверка на физическом устройстве и публикация
в магазине не выполнялись. Платежи демонстрационные, согласно ТЗ.
Сервер нужен для работы: локальный эмулятор использует 10.0.2.2:8000.
Облачное размещение и коммерческая эксплуатация в этот комплект не входят.

16 экранов созданы в Figma до реализации. Лимит Starter остановил финальную
правку стандартных иконок нижней навигации и экспорт макета;
подробности в [дизайн-документе](../design/README.md).
